Execution and risk

Each run starts with its own virtual balance (default $1,000). Selected stocks share that balance. Sweep variants have separate portfolios. Costs and open-position losses count toward equity.

Parameter sweep · up to 500 variants

Each variant is saved, including failures. A large sweep increases the chance of finding a lucky result.

Final reserved holdout

Freeze one candidate first. This consumes the dataset's one final evaluation, even if it fails. Repeated tuning after seeing it invalidates its purpose.

Additional research ideas and evidence

CAPM is a return attribution model, not an entry signal. Results estimate realized beta and alpha against SPY when 30 aligned observations are available. Factor models, routine-versus-opportunistic insider classification, and liquidity controls need richer historical data before implementation.

The broker-time NASDAQ daily-long screenshot and USDJPY morning-range screenshot are documented in the project plan; their product, timezone, financing and FX data requirements are unresolved, so they are not presented as runnable stock strategies.

    A local rehearsal on stored data. Each step reveals one session and retains open positions. It is not live paper execution and never submits broker orders.

    In Strategies, configure a strategy and select Add to portfolio. Add 2–5 allocations using the same dataset and dates. Divide one total balance between them; unused cash stays in each allocation. Minimum $100 per allocation.

    Connections
    Credentials stay in the local .env file and are never returned to the browser.
    Create .env in the project folder. Alpaca keys should belong to a paper account. This application has no live order route.
    Research rules
    The final 20% of each dataset is reserved for one frozen evaluation. Sweep variants and walk-forward folds are all recorded. Ranking historical winners does not establish predictive ability.
    Currency is USD for the bundled sample and Alpaca imports. A €5 goal requires an explicit FX model, which is not implemented. Data is stored under var/; preserve it to retain experiment history.
